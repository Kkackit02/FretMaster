# FretMaster

기타 지판 음 위치를 외우기 위한 연습 프로그램입니다.
화면에 음(예: **3번 줄 A**)이 나오면 기타로 그 음을 치세요. 마이크로 소리를 듣고 맞았는지 바로 알려줍니다.

## 실행

**https://kkackit02.github.io/FretMaster/** 에서 바로 쓸 수 있습니다.
Chrome·Edge 주소창이나 화면 위쪽의 **앱 설치** 버튼으로 앱처럼 설치하면, 홈 화면 아이콘으로 열리고 인터넷 없이도 동작합니다 (휴대폰은 브라우저 메뉴의 "홈 화면에 추가").

로컬에서는 `index.html`을 Chrome / Edge로 열면 됩니다.

마이크 권한 문제로 잘 안 열리면 로컬 서버로 띄우세요:

```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 사용법

1. 위쪽 분류(기타 연습 / 이론+청음 / 잼 연습 / 드럼 / 기록)와 그 아래 탭에서 연습 모드 고르기
2. **시작** → 마이크 허용 (지판 찍기·건반 코드는 마이크 없이 바로 시작, 스케일·귀 훈련·코드 가이드·드럼 루디먼트는 각자 화면이 있는 탭)
3. 문제를 기타로 치기
4. 막히면 **힌트(H)** 로 위치 보기, **건너뛰기(Space)** 로 답 보고 넘어가기

### 연습 모드

| 모드 | 문제 | 하는 일 |
|---|---|---|
| **단음** | `3번 줄 A` | 그 음을 친다. 틀리면 친 음과 위치를 알려줌 |
| **코드 구성음** | `Am7` | 구성음(A·C·E·G)을 한 음씩 아무 줄·옥타브에서 친다. 찾을 때마다 칸이 채워지고, 다 찾으면 지판에 모든 구성음 위치를 보여줌 |
| **코드 스트럼** | `Am7` | 코드를 잡고 한 번에 긁는다. 아래 막대 그래프에 지금 들리는 음 분포가 나옴 |
| **코드 전환** | `C ↔ G` | 두 코드를 30·60·120초 동안 번갈아 치고 마이크로 전환 횟수를 셈. 코드 짝별 최고 기록과 추이 그래프 |
| **지판 찍기** | `3번 줄 A` 또는 `Am7` | 마이크 없이 화면의 지판 칸을 눌러 답한다. 음 위치 문제는 줄·프렛까지 정확히 판정, 코드 문제는 구성음 자리를 하나씩 찍는다 |
| **건반 코드** | `Am7` | 마이크 없이 피아노 건반을 눌러 구성음을 완성한다. 누른 음은 소리가 나고, 완성하면 코드를 들려주며 기타 지판에서의 위치도 보여줌 |
| **스케일** | `A 마이너 펜타토닉` | 포지션 운지를 보고 듣고, 지판을 눌러 또는 기타로 쳐서(마이크) 순서대로 따라간다 (아래 참고) |
| **트라이어드** | `C · 1전위 · 2·3·4번 줄` | 줄 세트별 3화음 기본형·1전위·2전위 지도를 보고, 퀴즈로 지판에서 찍기 (아래 참고) |
| **음정 모양** | `D4에서 완전4도 위` | 근음에서 음정 자리를 지판에서 찍는 퀴즈 + 근음 둘레 음정 지도 |
| **귀 훈련** | `어떤 음정일까요?` | 소리를 듣고 음정·코드 종류를 맞히거나, 들리는 음을 지판에서 찾아 누른다 (아래 참고) |
| **오선보** | 음표 하나 | 오선보 음표의 이름 맞히기(높은·낮은음자리표, 덧줄, ♯♭) 또는 기타 지판에서 찾기 (아래 참고) |
| **코드 가이드** | – | 퀴즈 없이 코드를 찾아보고, 5도권으로 코드 진행을 만든다 (아래 참고) |
| **진행 분석** | `C E7 Am C7 F Fm C` | 코드 진행을 입력하면 키·로마 숫자·기능을 붙이고 키 밖 코드와 종지를 설명. 조옮김·카포 추천, 잼 트랙·코드 가이드로 보내기 |
| **잼 트랙** | `Dm7 → G7 → CM7` | 코드 진행 + 드럼 + 베이스 + 코드 반주를 반복 재생, 위에서 쓸 스케일과 지금 코드의 구성음을 지판에 표시 |
| **드럼 루디먼트** | `싱글 패러디들` | 루디먼트·액센트·그루브·리딩 악보를 보고 소리로 들어 보기 (아래 참고) |
| **연습 기록** | – | 오늘·최근 7일 연습 시간, 연속 연습 일수, 정답률, 최근 14일 차트, 지판 약점 지도, 가장 약한 음, 코드 전환 기록 |

코드 종류: M, m, 7, M7, m7, sus2, sus4, dim, aug, m7♭5 (설정에서 선택)

**코드 범위**는 기본이 `자주 쓰는 코드`로, C·G·Am·E7·Dsus4 같은 오픈 코드 49개만 나옵니다.
`모든 근음`으로 바꾸면 12키 전부(G♯m7, E♭aug 등)가 나옵니다.

**운지 형태** (스트럼 모드) — 같은 코드를 여러 자리에서 잡는 연습
| 형태 | 예시 (C) | 있는 코드 종류 |
|---|---|---|
| 오픈 코드 | x32010 | 자주 쓰는 코드 49개 |
| 6번 줄 근음 바레 (E폼) | 8 10 10 9 8 8 | M, m, 7, M7, m7, sus4 |
| 5번 줄 근음 바레 (A폼) | x 3 5 5 5 3 | M, m, 7, M7, m7, sus2, sus4, dim, aug |

바레 코드는 12키 전부 나오고, 몇 프렛을 잡을지는 직접 찾아야 합니다 (근음 위치 외우기 연습).
힌트/정답을 보면 지판에 운지와 바레 막대가 표시됩니다 (× = 치지 않는 줄).
마이크는 어떤 음들이 울리는지만 들으므로, 다른 자리에서 같은 코드를 잡아도 정답이 됩니다.

### 스케일

- **스케일 종류:** 메이저, 내추럴 마이너, 메이저/마이너 펜타토닉, 블루스, 하모닉·멜로딕 마이너, 도리안·프리지안·리디안·믹솔리디안·로크리안
- **포지션:** 펜타토닉·블루스는 흔히 쓰는 5개 박스, 7음 스케일은 줄당 3음(3NPS) 7개 패턴. `지판 전체`를 고르면 설정의 프렛 범위 안 모든 자리
- **지판 표시:** 음이름 또는 도수(R, ♭3, 5 …). 근음은 주황
- **연습 방법**
  - ▶ 듣기: 정한 속도로 스케일을 들려주며 지금 나는 음을 지판에 표시
  - 지판으로 연습: 다음 음 자리를 순서대로 누름 (포지션 연습이면 정확한 자리만 인정)
  - 기타로 연습 (마이크): 마이크로 듣고 정확한 높이(옥타브까지)의 다음 음을 치면 넘어감
  - 방향: 올라가기 / 내려가기 / 올라갔다 내려오기. `운지 보여주기`를 끄면 다음 음 이름만 보고 외워서 치기
  - 실수 없이 완주하면 설정별 최고 기록 저장

### 귀 훈련

- **음정 맞히기:** 두 음을 들려주고(올라가며 / 내려가며 / 동시에 / 섞어서) 단2도~옥타브 중 고르기. 출제할 음정을 골라 쉬운 것부터 시작
- **코드 종류 맞히기:** 코드를 펼쳐서 한 번, 같이 한 번 들려주고 M / m / 7 / M7 … 중 고르기
- **음 찾기:** 들리는 음을 지판에서 찾아 누르기. 틀리면 "더 높아요 (3반음)"처럼 알려줌. 기준음 A 듣기 가능
- Space = 다시 듣기, H = 정답 보기. 결과는 위쪽 점수에 반영

### 메트로놈 (모든 탭)

- 화면 위쪽 막대. ▶로 켜고 BPM(30~260)·박자(2/4 ~ 6/4) 설정, 첫 박은 강하게
- **점점 빠르게:** N마디마다 +X BPM씩 최대값까지 올림 (스피드 트레이너)
- 클릭 소리는 음높이 없는 잡음이라 마이크 연습과 같이 켜 둬도 음 인식에 잡히지 않음

### 오선보

- **음이름 맞히기:** 높은음자리표 / 낮은음자리표, 오선 안 / 덧줄까지, ♯·♭ 포함 여부를 골라 연습 (헷갈리는 B♯·E♯·C♭·F♭은 안 나옴)
- **지판에서 찾기:** 기타 악보 기준. 기타는 실제 소리보다 **한 옥타브 높게** 적기 때문에(높은음자리표 아래 작은 8) 적힌 음보다 한 옥타브 낮은 자리가 정답. 틀리면 누른 음을 오선보에 빨갛게 겹쳐 그리고, 옥타브만 틀렸는지·얼마나 높고 낮은지 알려줌
- 소리 듣기, H = 정답 보기

### 진행 분석

- **입력:** `Am F C G`, `C | G/B | Am7 | F`, `Cmaj9 Am11 Dm9 G13`처럼 띄어쓰기·`|`·쉼표로 구분. 슬래시 코드 지원, 9·11·13·add9·6 같은 확장음은 가장 가까운 코드로 분석. `%` = 앞 코드 반복
- **키 추정:** 24개 키 중 가장 그럴듯한 키와 확신 정도, 다른 후보. 키를 직접 고를 수도 있음. 7th 코드가 대부분이면 블루스로 봄
- **코드마다:** 로마 숫자, 기능 T(토닉, 안정)·SD(서브도미넌트, 준비)·D(도미넌트, 긴장)
- **키 밖 코드 설명:** 세컨더리 도미넌트(V7/vi 등), 같은 으뜸음 조에서 빌려 온 코드(iv, ♭VII, ♭VI …), 나폴리 코드, 피카르디 3화음
- **흐름:** 정격·변격(아멘)·거짓 종지, 반종지로 끝남, ii–V–I
- **도구:** 조옮김(±6반음), 카포 추천(모든 코드가 자주 쓰는 코드 모양이 되는 카포 자리), 잼 트랙으로 보내기 / 코드 가이드로 보내기. 코드를 누르면 지판에 운지가 나오고 소리가 남

### 코드 가이드

- **코드 보기:** 구성음, 피아노 건반, 기타 운지(오픈 / E폼 / A폼 / 구성음 전체)를 보여주고 ▶ 듣기로 소리를 들려줌. 코드 종류 버튼으로 같은 근음의 다른 코드로 바꿀 수 있음
- **5도권 원:** 바깥은 장조 코드, 안쪽은 관계 단조 코드. 누를 때마다 코드 진행에 차례로 추가됨 (첫 코드가 키가 됨). 현재 키에서 자주 쓰는 코드 영역(IV·I·V와 ii·vi·iii)이 밝게 표시됨
- **이 키의 코드:** 다이어토닉 코드(I ii iii IV V vi vii°). `7화음으로`를 켜면 IM7 ii7 … viiø7
- **다음에 오기 좋은 코드:** 마지막 코드 기준 5도 아래(해결), 5도 위, 관계 장·단조, 그 코드로 가는 V7을 추천
- **코드 진행:** 로마 숫자(I, V, vi …)와 함께 표시. 재생·반복·BPM·코드당 박자 설정, 칩을 누르면 그 코드 보기, ×로 삭제. Space로 재생/정지
- **가이드톤 (3·7음):** 운지 선택에서 `가이드톤`을 고르면 3음(초록)·7음(파랑)만 표시. 진행 칩에도 가이드톤이 나오고, 아래 **가이드톤 흐름**에서 코드가 바뀔 때 3·7음이 어디로 움직이는지 보여줌 (예: Dm7 → G7에서 C(♭7) → B(3) 반음↓, F 유지)
- **가이드톤 연습:** 진행의 코드마다 3·7음을 지판에서 누르거나 기타로 쳐서(마이크) 찾기. `템포에 맞춰 넘어가기`를 켜면 BPM·코드당 박자대로 클릭과 함께 다음 코드로 넘어가고, 코드마다 성공(초록)/일부(주황)/놓침(빨강) 표시
- **자주 쓰는 진행:** I–V–vi–IV, ii–V–I, iii–vi–ii–V–I(5도권 진행), 캐논, 12마디 블루스, 단조 진행 등을 현재 키로 불러오기

### 드럼 루디먼트

탭 안에서 **루디먼트 / 액센트 / 그루브 / 리딩** 네 가지 모드를 고른다. 모두 악보를 보고 소리로 들어 보는 용도.

- **루디먼트 (20종):** 롤(싱글·더블·파이브·세븐 스트로크), 패러디들(싱글·더블·트리플, 패러디들-디들), 플램(플램, 플램 탭, 플램 액센트, 플라마큐, 플램 패러디들, 스위스 아미 트리플렛), 드래그, 손발 조합(RLK 셋잇단, RLRK, RLLK, RKLK, 가스펠 식스 RLRLKK)
  - 킥 넣기: 매 박 / 1·3박 / 액센트마다. 악보에서 킥은 줄 아래 음표, 스티킹은 K(초록)
- **액센트:**
  - 한 칸씩 옮기기(16분: 마디마다 1→e→&→a, 셋잇단: 1→2→3), N개마다 액센트(2~7, 박과 어긋나는 그룹핑), 무작위(새로 만들기 버튼), 직접 만들기(음표를 눌러 액센트 켜고 끄기)
  - 스티킹: 싱글 / 더블 / 패러디들 / 오른손만 / 왼손만
  - 업·다운 스트로크 표시: D 다운(높이에서 세게, 낮게 멈춤) · U 업(낮게 작게, 치면서 들어올림) · F 풀 · T 탭. 액센트와 탭의 소리 크기 차이를 크게 들려줌
- **그루브 (10종):** 기본 8비트, 8비트 변형 2가지, 4비트 록, 16비트, 하프타임, 디스코(오픈 하이햇), 셔플(스윙으로 재생), 원 드롭, 싱코페이션 킥. 5선 보표(하이햇 ×, 스네어, 킥)와 세는 법(1 e & a)
- **리딩:** 난이도(쉬움: 4분·8분·2분 / 보통: + 점4분·싱코페이션 / 어려움: + 16분 조합·점8분)와 길이(2·4마디)를 정해 무작위 리듬 악보를 만들고(새로 만들기 버튼 새 문제) 들어서 확인. 세는 법 표시 켜고 끄기
- **재생 (공통):** BPM, 반복, 박자 클릭, **템포 계단**(반복할 때마다 +N BPM, 최대값까지). Space = 재생/멈춤. 재생 중인 음표가 빨갛게 표시됨

### 트라이어드

- **지도 보기:** 근음·종류(M / m / dim / aug)·줄 세트(1-2-3, 2-3-4, 3-4-5, 4-5-6번 줄)를 고르면 지판 전체의 기본형(주황)·1전위(초록)·2전위(파랑) 자리를 도수(R·3·5) 또는 음이름으로 표시
- **퀴즈:** "Cm · 기본형 · 1·2·3번 줄"처럼 나오면 세 줄에 한 음씩 찍기. 다른 전위를 찍으면 "이건 1전위예요 (아래에서부터 3·5·R)"처럼 무엇을 잡았는지 알려줌. 출제할 종류·줄 세트 선택, H = 정답 보기

### 음정 모양

- **퀴즈:** 지판에 근음(R)이 표시되면 "완전4도 위" 같은 음정 자리를 찍기 (위로 / 아래로 / 섞어서, 출제할 음정 선택). 틀리면 그 자리가 근음에서 무슨 음정인지 알려주고, 맞히면 같은 음이 나는 다른 자리도 보여줌
- **모양 보기:** 지판을 누른 자리를 근음으로, 둘레(±5프렛)의 음정을 R·♭3·3·5·♭7 … 로 표시 (3도 초록, 5도 파랑)

### 잼 트랙

- **진행:** 입력칸에 `C G Am F`처럼 직접 입력(Enter로 적용, 키 자동 추정), 코드 가이드에서 가져오기, 또는 프리셋(I–V–vi–IV, ii–V–I, 12마디 블루스 …). 키를 바꾸면 진행도 함께 조옮김
- **반주:** 드럼 그루브 10종, 베이스(근음·5음), 코드(패드 / 2·4박 스탭), BPM, 코드당 2·4·8박. Space = 시작/멈춤. 재생 중에 바꿔도 바로 적용 (박 수를 바꾸면 지금 코드는 유지하고 길이만 바뀜)
- **스케일 추천:** 장조면 메이저 펜타토닉·메이저·믹솔리디안, 단조면 마이너 펜타토닉·마이너·블루스·도리안, 모두 7th 코드인 블루스 진행이면 블루스·마이너 펜타토닉·믹솔리디안 ((기본) = 첫 추천)
- **지판:** 스케일 음(회색) 위에 지금 코드의 구성음(초록, 근음 주황)이 코드가 바뀔 때마다 따라 바뀜 — 구성음에 머물면 잘 어울림

### 코드 전환 (1분 코드 체인지)

- 코드 A·B(오픈 코드)를 고르거나 자주 쓰는 짝(C↔G, G↔D, Am↔E …)을 누르고 시작. 3초 카운트다운 동안 첫 코드를 잡아 둠
- 코드를 칠 때마다 스트럼 인식으로 판정하고, 다른 코드로 바꿔 치면 1번으로 셈 (같은 코드를 다시 쳐도 안 셈)
- 지판에는 다음에 칠 코드의 운지가 표시됨. 끝나면 분당 전환 횟수·평균 전환 시간·최고 기록, 같은 짝의 기록 추이 그래프

### 연습 기록

- 연습 시간은 화면이 보이고 최근 1분 안에 무언가 했을 때(누르기·키보드·마이크 소리)만 쌓임. 연속 연습 = 하루 1분 이상 또는 문제를 푼 날
- **지판 약점 지도:** 단음·지판 찍기에서 자주 틀리거나 느린 자리를 연한 색(잘함) → 진한 색(약함)으로 표시, 점선 = 아직 안 해 본 자리. 칸에 마우스를 올리면 정답률·평균 시간
- 기록은 이 브라우저에만 저장됨 (기기끼리 공유되지 않음)

### 휴대폰

- 세로 화면에서는 지판을 세로로 세워 보여줌 (코드 다이어그램처럼 왼쪽이 6번 줄, 위가 0프렛). 가로로 돌리면 원래 지판
- 모든 탭이 좁은 화면에서 가로로 넘치지 않게 맞춤

### 학습 모드

- 문제를 내는 탭(단음, 코드 구성음, 코드 스트럼, 지판 찍기, 건반 코드, 트라이어드·음정 모양 퀴즈, 오선보)의 탭 설명 옆 **학습 모드 (힌트 항상 표시)** 를 켜면 문제마다 정답 위치가 처음부터 표시됨
- 보면서 익히는 연습이라 약점 기록(히트맵·약한 음 출제)과 연속 정답에는 반영하지 않음
- 코드 문제에서는 구성음이 왜 그렇게 되는지 설명이 함께 나옴: 근음에서의 음정(예: `Cm7 = C(근음) + E♭(단3도, 3반음) + …`)과 3도 쌓기(`C →단3도→ E♭ →장3도→ G …`). 트라이어드 퀴즈는 전위 설명(`1전위: 맨 아래 3음(E) → 아래부터 E·G·C`)도 추가

## 알아둘 점

- 표준 튜닝(E A D G B E) 기준입니다. 연습 전에 튜닝을 맞춰 주세요 (화면의 튜너 표시를 참고해도 됩니다).
- 마이크는 **음높이**만 들을 수 있어서 어느 줄로 쳤는지는 구분하지 못합니다.
  예를 들어 "2번 줄 E"(2번 줄 5프렛 = E4)를 1번 줄 개방현으로 쳐도 같은 음이라 정답으로 처리됩니다.
- 단음·코드 구성음 모드는 한 번에 한 음씩 쳐 주세요.
- 코드 스트럼 모드는 음높이 분포로 판정하므로, 구성음이 같은 코드(예: Dsus4 = Gsus2, Caug = Eaug)는 모두 정답으로 인정됩니다.
  5음은 생략하는 보이싱이 많아 5음이 안 들려도 통과합니다. 뮤트된 줄이 많거나 한 줄만 크게 울리면 다른 코드로 들릴 수 있어요.
