# FretMaster

기타 지판 음 위치를 외우기 위한 연습 프로그램입니다.
화면에 음(예: **3번 줄 A**)이 나오면 기타로 그 음을 치세요. 마이크로 소리를 듣고 맞았는지 바로 알려줍니다.

## 실행

설치할 것 없이 `index.html`을 Chrome / Edge로 열면 됩니다.

마이크 권한 문제로 잘 안 열리면 로컬 서버로 띄우세요:

```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 사용법

1. 위쪽 탭에서 연습 모드 고르기
2. **시작** → 마이크 허용 (지판 찍기·건반 코드 모드는 마이크 없이 바로 시작)
3. 문제를 기타로 치기
4. 막히면 **힌트(H)** 로 위치 보기, **건너뛰기(Space)** 로 답 보고 넘어가기

### 연습 모드

| 모드 | 문제 | 하는 일 |
|---|---|---|
| **단음** | `3번 줄 A` | 그 음을 친다. 틀리면 친 음과 위치를 알려줌 |
| **코드 구성음** | `Am7` | 구성음(A·C·E·G)을 한 음씩 아무 줄·옥타브에서 친다. 찾을 때마다 칸이 채워지고, 다 찾으면 지판에 모든 구성음 위치를 보여줌 |
| **코드 스트럼** | `Am7` | 코드를 잡고 한 번에 긁는다. 아래 막대 그래프에 지금 들리는 음 분포가 나옴 |
| **지판 찍기** | `3번 줄 A` 또는 `Am7` | 마이크 없이 화면의 지판 칸을 눌러 답한다. 음 위치 문제는 줄·프렛까지 정확히 판정, 코드 문제는 구성음 자리를 하나씩 찍는다 |
| **건반 코드** | `Am7` | 마이크 없이 피아노 건반을 눌러 구성음을 완성한다. 누른 음은 소리가 나고, 완성하면 코드를 들려주며 기타 지판에서의 위치도 보여줌 |
| **코드 가이드** | – | 퀴즈 없이 코드를 찾아보고, 5도권으로 코드 진행을 만든다 (아래 참고) |

코드 종류: Major, m, 7, maj7, m7, sus2, sus4, dim, aug, m7♭5 (설정에서 선택)

**코드 범위**는 기본이 `자주 쓰는 코드`로, C·G·Am·E7·Dsus4 같은 오픈 코드 49개만 나옵니다.
`모든 근음`으로 바꾸면 12키 전부(G♯m7, E♭aug 등)가 나옵니다.

**운지 형태** (스트럼 모드) — 같은 코드를 여러 자리에서 잡는 연습
| 형태 | 예시 (C) | 있는 코드 종류 |
|---|---|---|
| 오픈 코드 | x32010 | 자주 쓰는 코드 49개 |
| 6번 줄 근음 바레 (E폼) | 8 10 10 9 8 8 | Major, m, 7, maj7, m7, sus4 |
| 5번 줄 근음 바레 (A폼) | x 3 5 5 5 3 | Major, m, 7, maj7, m7, sus2, sus4, dim, aug |

바레 코드는 12키 전부 나오고, 몇 프렛을 잡을지는 직접 찾아야 합니다 (근음 위치 외우기 연습).
힌트/정답을 보면 지판에 운지와 바레 막대가 표시됩니다 (× = 치지 않는 줄).
마이크는 어떤 음들이 울리는지만 들으므로, 다른 자리에서 같은 코드를 잡아도 정답이 됩니다.

### 코드 가이드

- **코드 보기:** 구성음, 피아노 건반, 기타 운지(오픈 / E폼 / A폼 / 구성음 전체)를 보여주고 ▶ 들어보기로 소리를 들려줌. 코드 종류 버튼으로 같은 근음의 다른 코드로 바꿀 수 있음
- **5도권 원:** 바깥은 장조 코드, 안쪽은 관계 단조 코드. 누를 때마다 코드 진행에 차례로 추가됨 (첫 코드가 키가 됨). 현재 키에서 자주 쓰는 코드 영역(IV·I·V와 ii·vi·iii)이 밝게 표시됨
- **이 키의 코드:** 다이어토닉 코드(I ii iii IV V vi vii°). `7화음으로`를 켜면 Imaj7 ii7 … viiø7
- **다음에 오기 좋은 코드:** 마지막 코드 기준 5도 아래(해결), 5도 위, 관계 장·단조, 그 코드로 가는 V7을 추천
- **코드 진행:** 로마 숫자(I, V, vi …)와 함께 표시. 재생·반복·BPM·코드당 박자 설정, 칩을 누르면 그 코드 보기, ×로 삭제. Space로 재생/정지
- **자주 쓰는 진행:** I–V–vi–IV, ii–V–I, iii–vi–ii–V–I(5도권 진행), 캐논, 12마디 블루스, 단조 진행 등을 현재 키로 불러오기

## 설정

| 항목 | 설명 |
|---|---|
| 문제 종류 (지판 찍기) | 음 위치 / 코드 구성음 |
| 출제 방식 (단음, 지판 찍기) | `줄 + 음이름`: 특정 줄에서 찾기 / `음이름만`: 어느 줄에서든 해당 음을 치면 정답 |
| 코드 범위 (코드 모드) | 자주 쓰는 코드(오픈 코드 중심) / 모든 근음 |
| 코드 종류 (코드 모드) | 출제할 코드 종류 |
| 구성음 순서대로 | R → 3 → 5 → 7 순서로 쳐야 인정 |
| 건반에 음이름 표시 (건반 코드) | 끄면 건반 이름 없이 위치만으로 찾기 |
| 연습할 줄 / 프렛 범위 | 연습 범위 제한 (예: 6·5번 줄 0~12프렛부터 시작) |
| 음이름 표기 | C D E 또는 도 레 미 |
| 변화음 표기 | 관용 표기(B♭, E♭, F♯, C♯m 등 실제 악보에서 흔한 쪽) / ♯ / ♭ / 섞어서 |
| 자연음만 | ♯·♭ 음 제외 |
| 약한 음 자주 출제 | 자주 틀리거나 오래 걸린 음을 더 자주 냄 (기록은 브라우저에 저장) |
| 마이크 감도 | 레벨 미터의 빨간 선보다 기타 소리가 커야 인식합니다. 주변 소음이 잡히면 낮추세요 |

## 알아둘 점

- 표준 튜닝(E A D G B E) 기준입니다. 연습 전에 튜닝을 맞춰 주세요 (화면의 튜너 표시를 참고해도 됩니다).
- 마이크는 **음높이**만 들을 수 있어서 어느 줄로 쳤는지는 구분하지 못합니다.
  예를 들어 "2번 줄 E"(2번 줄 5프렛 = E4)를 1번 줄 개방현으로 쳐도 같은 음이라 정답으로 처리됩니다.
- 단음·코드 구성음 모드는 한 번에 한 음씩 쳐 주세요.
- 코드 스트럼 모드는 음높이 분포로 판정하므로, 구성음이 같은 코드(예: Dsus4 = Gsus2, Caug = Eaug)는 모두 정답으로 인정됩니다.
  5음은 생략하는 보이싱이 많아 5음이 안 들려도 통과합니다. 뮤트된 줄이 많거나 한 줄만 크게 울리면 다른 코드로 들릴 수 있어요.

## 구조

- `index.html` / `style.css` — 화면
- `app.js` — 모드별 출제·판정, 지판 그리기, 설정
- `pitch.js` — YIN 알고리즘 기반 피치 검출, 코드 인식용 크로마 분석
- `guide.js` — 코드 가이드, 5도권, 코드 진행
- `chords.js` — 코드 구성음·철자(B♭ D F 등), 자주 쓰는 코드·바레 운지표, 크로마 템플릿 매칭
